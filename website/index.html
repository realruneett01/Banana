Built for reviewing hardware changes

Everything a design review needs, without opening KiCad twice.

Geometry diff, not text diff

Both versions are rendered with KiCad’s own exporter, then matched in several passes — reference designators, exact shapes, nearby shapes, copper track chains — so a moved part is reported once, not as hundreds of line changes.

Mapped to nets and pads

Every difference is traced back to the footprint, pad or net it belongs to, using the parsed board file. “Added GND trace” beats “path changed”.

Side-by-side and overlay

Synchronised pan and zoom, a before/after slider, per-layer control and pad labels. Unchanged geometry fades to grey so changes stand out.

History, not just two points

Step through every commit that touched a file between two revisions with the evolution timeline.

Local Git or GitHub

Read commits straight from a repository on your machine, or connect GitHub to diff branches, commits and pull requests.

Banana Studio: design boards with your AI assistant

Switch to Studio, describe a board, and watch KiCad draw it. The assistant uses real KiCad library parts, routes the board, runs checks and an ngspice simulation, and saves each answer as one step you can undo or compare in the diff. You can also drag, rotate and edit parts yourself, and export Gerbers, BOM and pick-and-place files. Results are drafts to review, not finished products; the assistant needs your own Gemini key.

Checks itself before it starts

Each launch verifies file integrity, finds KiCad, picks a free port and proves the diff engine on a known pair of boards. If anything is off, it tells you instead of failing quietly.

Setting up for a team?

Turn on sign-in so only your people can open it: set BANANA_AUTH=required, then create accounts with npm run user -- add <name>. Passwords are stored hashed, sessions expire, and failed sign-ins are rate-limited. Docker and systemd setups are in the README.

Questions

Does Banana upload my designs?

No. With a local repository, files are read and rendered on your computer. If you connect GitHub, Banana downloads the files you choose from GitHub. The optional AI Copilot sends the context of your question to Google Gemini, and only when you use it with your own API key.

Which KiCad versions work?

KiCad 7 and newer. Banana reads what your installed kicad-cli offers and adapts. Version 7 is fully tested; 8 and later are exercised by an automated test matrix that is still being brought to green, so treat them as less proven.

Which operating systems are supported?

Banana is built for Windows, macOS and Linux on x64 and ARM — the download is the same everywhere. Linux x64 is the most thoroughly tested today; Windows, macOS and ARM are covered by automated checks that are still being rolled out, so report anything odd.

Is there an installer?

Not yet. Banana is a portable folder: unzip and run the launcher. The download for your system already includes Node.js; you only need KiCad and Git on the computer. It also runs from a USB drive.

My computer shows a security warning — is that normal?

It can be. Banana’s own launcher scripts are not code-signed (that costs money and is not done yet), so Windows or macOS may ask you to confirm. Compare the SHA-256 shown on this page with your file first (steps above); if they match, the file is exactly what was published. The bundled Node.js is the official, unmodified build from nodejs.org.

Will it start by itself when I plug in a USB drive?

No — modern operating systems block that, for good reason. Open the drive and run the launcher.

What does it check at start-up?

That its files are intact, that Node, Git and KiCad are present and working, that a port and scratch space are available, and that its diff engine gives the right answer on a built-in pair of test boards. It refuses to start if any of those fail.

Is it really free? Can I use it at work?

Yes. Banana is free for personal, educational and commercial use, with no sign-up. It is proprietary rather than open source: the source code is private and you may not redistribute, modify or reverse engineer it. The full terms are in the LICENSE file inside the download.
